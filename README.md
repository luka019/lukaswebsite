# Luka / Law

Bilingual, static technology-law practice website for Luka Shakhkulashvili.

Live site: https://luka019.github.io/lukaswebsite/
Repository: https://github.com/luka019/lukaswebsite

## Files and publishing

- `index.html`: complete Georgian default content, with English translations in `data-en` attributes.
- `styles.css`: responsive layout and locally served fonts.
- `script.js`: language preference and accessible mobile navigation.
- `assets/`: local fonts and the London architecture photograph.
- `.nojekyll`: keeps GitHub Pages as a simple static site.

GitHub Pages publishes the `main` branch, repository root. Keep paths relative so the project subdirectory works. CSS and JavaScript URLs include a version marker to reduce stale browser caching.

Preview locally with `python3 -m http.server 4173 --bind 127.0.0.1`.
The page is readable without JavaScript; service disclosures use native HTML details.
English links can be shared using `?lang=en`; Georgian using `?lang=ka`.

## Content safeguards

- Luka is the only individually named public profile. Other expertise is described as matter-specific team support.
- University and employer references describe the founder’s background; they are not endorsements or firm partnerships.
- LLM is described as studies, rather than asserting an unconfirmed award date.
- No fabricated office address, staff count, client logos, testimonials or email address.
- The contact buttons open the supplied LinkedIn profile. No form or backend claims to submit enquiries.
- Banking, immigration, tax eligibility and regulatory approvals are case-specific; no result guarantees.
- Foreign-law advice and technical cybersecurity testing require appropriately qualified specialists.
- Scope and fees must be agreed in writing. Review regulated-service wording and professional obligations before offering a new service.
- No analytics or advertising trackers. Only language preference uses local storage.
