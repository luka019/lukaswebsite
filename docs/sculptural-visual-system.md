# DLG visual system — 7 November 2026

The public interface uses an ivory editorial surface, navy architecture and small bronze accents. The original generated hero artwork is shipped locally as a 65 KB WebP; it does not add an external image service or runtime dependency. The founder photograph is unchanged.

`scripts/visual-system.mjs` owns the decorative SVG motifs and the homepage legal lens. `firm.css` remains the shared design stylesheet. `visual-experience.js` progressively enables the lens, one-time entrance transitions and subtle fine-pointer artwork tilt. The existing hero pause control also stops these decorative effects. Reduced motion suppresses them automatically.

Without JavaScript, all four legal-lens articles and service links remain available; only their inactive controls are hidden. With JavaScript, one panel is shown at a time. Arrow keys and Home/End change the selection. The diagram follows the selected panel. Georgian and English pages are rendered statically with localized links.

Publication checks: build, public static QA, resource tests, browser QA at nine viewport widths, keyboard interaction, no-JavaScript English fallback, reduced motion, mobile detail routes, and visual review of desktop/mobile screenshots. No client counts, testimonials or professional credentials were added. Existing service content and the future-domain configuration are preserved.
