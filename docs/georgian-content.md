# ქართული ტექსტის სარედაქციო პრინციპები

საიტის ტექსტი იწერება ქართულად, ქართული სამართლებრივი და ბიზნესმეტყველების გათვალისწინებით. ინგლისური ფრაზის სიტყვასიტყვითი თარგმანი საკმარისი არ არის. ქვემოთ მოცემული არჩევანი საიტის სარედაქციო სტანდარტია და არა ქართული ენის ზოგადი გრამატიკული წესების ჩამონათვალი.

| კონტექსტი | საიტზე გამოყენებული ფორმა |
|---|---|
| ნავიგაცია და იურიდიული დახმარების ერთიანი შეთავაზება | მომსახურება / იურიდიული მომსახურება |
| სამართლებრივი მომსახურების გაწევის სუბიექტი | მომსახურების მიმწოდებელი |
| Trademark | სასაქონლო ნიშანი |
| Special categories of personal data | განსაკუთრებული კატეგორიის მონაცემები |
| Data processing agreement | მონაცემთა დამუშავების ხელშეკრულება (DPA) |
| Subprocessor | მონაცემთა დამუშავებაში ჩართული ქვეკონტრაქტორი; სამართლებრივი როლი განიმარტება შესაბამის კონტექსტში |
| Payment services provider | საგადახდო მომსახურების პროვაიდერი |
| VASP | ვირტუალური აქტივის მომსახურების პროვაიდერი |
| AI governance | ხელოვნური ინტელექტის მმართველობა / AI-ის მმართველობა |
| Acceptance of completed work | შესრულებული სამუშაოს ჩაბარება-მიღება |
| Exit arrangements | ხელშეკრულების / მომსახურების შეწყვეტის პირობები |
| Chain of title | უფლებების კუთვნილება და გადაცემა |
| Legal operations | იურიდიული პროცესების მართვა |

„იურიდიული“ გამოიყენება პროფესიული მომსახურების, კონსულტაციისა და სამსახურის აღსაწერად; „სამართლებრივი“ — შეფასების, მოთხოვნის, საფუძვლისა და საკითხის მიმართ. ეს არჩევანი მექანიკურად ყველა წინადადებაზე არ ვრცელდება.

სათაური მოკლედ განმარტავს მიმართულებას. აღწერაში ჩანს, რა საკითხს ვაფასებთ და რას მიიღებს კლიენტი. აბრევიატურები, როგორიცაა IP, განიმარტება ქართულად; ტექნოლოგიურ ბიზნესში დამკვიდრებული AI, IT, SaaS და CRM შეიძლება დარჩეს შესაბამის განმარტებასთან ერთად. სასერტიფიკაციო და საგანმანათლებლო დაწესებულებების სახელები ინარჩუნებს ოფიციალურ ფორმას.

ოფიციალური ტერმინების წყაროები:

- [კანონი „სასაქონლო ნიშნების შესახებ“](https://www.matsne.gov.ge/ka/document/view/11482)
- [კანონი „პერსონალურ მონაცემთა დაცვის შესახებ“](https://www.matsne.gov.ge/ka/document/view/5827307)
- [საქართველოს ეროვნული ბანკი — საგადახდო მომსახურების პროვაიდერები](https://nbg.gov.ge/page/payment-service-providers)
- [საქართველოს ეროვნული ბანკი — ვირტუალური აქტივის მომსახურების პროვაიდერები](https://nbg.gov.ge/page/virtual-asset-service-providers-vasps)

ახალი ტექსტის დამატებისას მოწმდება: ქართული წინადადების წყობა, პროფესიული ტერმინის მნიშვნელობა, განმარტების გასაგებობა, თანმიმდევრულობა, ასევე სათაურისა და ღილაკის განთავსება მობილურ და დიდ ეკრანზე. არასწორი ფორმის შესწორებისას იცვლება საწყისი მონაცემი ან შაბლონი, შემდეგ კი თავიდან გენერირდება ორივე ენობრივი ვერსია.
